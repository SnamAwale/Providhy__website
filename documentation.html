Inventory Management

The Inventory module is the heart of Providhy. It allows you to track stock levels, manage multiple godowns, set reorder points, and monitor expiry dates.

Key Features

Multi-Godown Support

Manage stock across multiple warehouses and track inter-godown transfers.

Low Stock Alerts

Get notified when products fall below minimum stock levels.

Expiry Tracking

Monitor batch-wise expiry dates for perishable goods.

Unit Conversion

Sell in pieces while purchasing in boxes with automatic conversion.

Adding a New Product

To add a new product to your inventory:

  1. Navigate to Inventory → Products
  2. Click the + Add Product button
  3. Fill in the product details (name, category, unit, etc.)
  4. Set the selling price and purchase price
  5. Configure tax rates if applicable
  6. Click Save
Example: Product Fields 
{
  "name": "Basmati Rice 5kg",
  "sku": "RICE-BAS-5KG",
  "category": "Grains",
  "unit": "Bag",
  "purchase_price": 450,
  "selling_price": 520,
  "tax_rate": 13,
  "min_stock": 50,
  "godown": "Main Warehouse"
}

Sales & Billing

The Sales module enables you to create invoices, manage quotations, track orders, and process returns — all while staying compliant with Nepal's tax regulations.

Invoice Types

Invoice Type Use Case Tax
VAT Tax Invoice B2B sales with PAN number 13% VAT
Abbreviated Invoice Retail sales (no PAN required) 13% VAT
Quotation Price estimates for customers N/A
Credit Note Sales returns & adjustments Reversal

Creating a Sales Invoice

  1. Go to Sales → New Invoice
  2. Select the customer (or add new)
  3. Choose invoice type (VAT/Abbreviated)
  4. Add products using search or barcode
  5. Apply discounts if needed
  6. Select payment mode (Cash/Credit/Digital)
  7. Click Save & Print

Important: Invoice Numbering

VAT invoices must follow sequential numbering as per IRD guidelines. Providhy automatically manages this for you — never manually edit invoice numbers.
